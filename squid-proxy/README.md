# Home Assistant Add-on: Squid Proxy

Servidor de proxy HTTP/HTTPS de alto desempenho com cache e autenticação para Home Assistant.

## Instalação Rápida
Copie esta pasta para `/addons/squid-proxy/` no seu Home Assistant, vá até a Loja de Add-ons, clique em "Verificar atualizações" e instale-o da seção "Add-ons Locais".
